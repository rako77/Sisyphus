# dupdetect — C# duplication audit

A one-off audit tool that finds duplicated logic in a C# codebase, including copies that were
renamed or modified, and writes a ranked HTML report with a suggested consolidation for each group.

```
extractor/   Roslyn console app: .cs files  ->  chunks.jsonl (one line per method-like chunk)
pipeline/    dupdetect.py: chunks.jsonl  ->  report.html + report.json
             ts_extract.py: tree-sitter stand-in for the extractor (no .NET needed, less precise)
sample/      a small solution with planted duplicates and boilerplate, for trying it out
```

## Quick start

```bash
# 1. Extract (needs the .NET 8+ SDK)
cd extractor
dotnet run -c Release -- /path/to/your/repo -o ../chunks.jsonl

# 2. Analyze
cd ../pipeline
pip install numpy scipy scikit-learn anthropic      # anthropic only for --llm
python dupdetect.py ../chunks.jsonl -o ../audit                       # offline first pass
python dupdetect.py ../chunks.jsonl -o ../audit --embedder voyage --llm anthropic   # full pass
open ../audit/report.html
```

Keys come from the environment: `VOYAGE_API_KEY` or `OPENAI_API_KEY` for embeddings,
`ANTHROPIC_API_KEY` for `--llm anthropic`.

Embeddings and LLM answers are cached in `<out>/.cache`, so re-running with a different threshold
or filters costs nothing extra.

## What happens

| Stage | What it does |
|---|---|
| Extract | One Roslyn compilation per project, so locals, parameters, fields and type parameters resolve through the semantic model. Chunks are methods, constructors, operators, accessors with bodies, local functions and block-bodied lambdas. Generated code (`*.g.cs`, `*.Designer.cs`, `Migrations/`, `<auto-generated>`, `[GeneratedCode]`) is skipped. |
| Normalize | Locals/params → `v1, v2…`, fields → `f1…`, generic params → `g1…`, literals → `STR`/`NUM`/`CHR`, `this.` and `.ConfigureAwait(...)` dropped, `var`/explicit local types → `T`, `=> x` ≡ `{ return x; }`, leading guard clauses (`ThrowIfNull`, `if (…) throw`) dropped. Member and type names are kept, since they carry meaning. |
| Filter | Drops tests, `Program.cs`/`Startup.cs`, tiny chunks, and boilerplate flagged by the extractor: forwarders, trivial constructors, `Equals`/`GetHashCode`/operators, `ToString`, `Dispose`, `INotifyPropertyChanged` plumbing, DI wiring. |
| Hash | Exact copies (same raw tokens) and renamed copies (same normalized tokens). These need no LLM. |
| Retrieve | Embeds every chunk, finds the top-k neighbours of each, keeps pairs above the threshold. |
| Verify | With `--llm`, a cheap model classifies each candidate pair as equivalent / near_duplicate / related / different. Only the first two link clusters. |
| Cluster | Connected components, then average-linkage inside each so that A≈B and B≈C don't chain A and C into one group unless the group is cohesive. |
| Summarize | With `--llm`, a stronger model writes a title, the behavioural differences between variants, a suggested abstraction and signature, the risk and the effort for each top cluster. |
| Report | Clusters are ranked by (copies − 1) × median lines, boosted when copies span projects or types. Each shows the locations, the assessment, the most central version, and a diff of every variant against it. Pairs the verifier called "related" are listed separately as look-alikes, since a small difference between near-identical code is sometimes a bug. |

## Choosing settings

**Embedder.** `tfidf` (default) runs offline over the normalized tokens. It is good at
copy-paste-and-edit duplicates and weak at semantic ones (a `foreach` loop vs. the same logic in
LINQ). For the real audit, use a code embedding model: `--embedder voyage` (voyage-code-3) or
`--embedder openai` (text-embedding-3-large), or a local model with `--embedder st:<model>`
(needs `sentence-transformers`).

**Threshold.** The defaults (tfidf 0.55, API embedders 0.80, local 0.85) are starting points,
not calibrated values. The run prints the distribution of nearest-neighbour similarity. Do a
first pass, look at the lowest-similarity clusters in the report, and raise or lower `--threshold`
until the bottom of the list is borderline. With `--llm`, err low: the verifier removes false
positives.

**Cost.** Pair verification sends two snippets per pair, capped by `--max-llm-pairs` (default 2000,
most similar first). Cluster summaries are capped by `--max-llm-clusters` (default 60). The model
names default to `claude-haiku-5-5` and `claude-sonnet-5-5` and can be changed with
`--pair-model` and `--cluster-model`.

**Other useful flags:** `--include-tests`, `--keep-noise`, `--exclude-path REGEX`,
`--min-tokens` (default 40), `--top-k` (default 8), `--link-threshold`, `--max-cluster`.
Run `python dupdetect.py -h` for the full list. The extractor takes `--exclude-dir`,
`--include-generated`, `--min-tokens` and `--define`.

## Chunk schema (chunks.jsonl)

```json
{"id": "src/Shop.Orders/OrderService.cs:30:5:method", "file": "...", "project": "Shop.Orders",
 "namespace": "Shop.Orders", "type": "OrderService", "member": "Validate", "kind": "method",
 "signature": "List<string> Validate(Order order)", "startLine": 30, "endLine": 50,
 "codeLines": 14, "tokens": 142, "statements": 13, "parentId": null,
 "flags": ["test", "forwarder", ...], "hints": ["mapping", "repository", "linqQuery"],
 "exactHash": "...", "normalizedHash": "...", "code": "...", "normalized": "( Order v1 ) { ... }"}
```

`kind` is one of method, constructor, destructor, operator, accessor, localFunction, lambda.
`parentId` links a lambda or local function to its enclosing chunk; the pipeline never pairs a
chunk with its own parent, and drops clusters that only repeat the inner lambdas of a reported one.

## Limitations

- The extractor references only the .NET framework assemblies, not NuGet packages or other
  projects. Local, parameter and field resolution doesn't need them; for anything that fails to
  resolve, it falls back to the names it found syntactically.
- Partial methods split across files, and duplication smaller than a method (repeated blocks
  inside larger methods), are not detected.
- `ts_extract.py` has no semantic model, so it identifies locals and fields by name only.
  Use it when .NET isn't available; prefer the Roslyn extractor for the real audit.
